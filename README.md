# Tanhim Malik — Portfolio

My personal portfolio, live at **[tanhimmalik.vercel.app](https://tanhimmalik.vercel.app)**.

A single page with my work, experience, the tools I use and how to reach me. It has light and dark mode, and a few small animations: glows that drift and follow the cursor, cards that light up on hover, and numbers that count up as you scroll to them.

## Built with

- React + TypeScript
- Vite
- Tailwind CSS v4
- Phosphor icons
- Deployed on Vercel

## Running locally

```bash
npm install
npm run dev
```

Most of the content (projects, experience, stack) lives in `src/data.ts`.
